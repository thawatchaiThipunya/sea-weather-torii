## 3D models

- `models/fishing-boat.glb` — [Fishing boat by Innerscene](https://www.innerscene.com/tools/library/3d-parts/fishing-boat-3c5a6bfd), CC0.
- The fisherman is assembled from Three.js primitives and does not use an external model.
- `models/barramundi-fish.glb` — [Barramundi Fish by Khronos glTF Sample Assets](https://github.com/KhronosGroup/glTF-Sample-Assets/blob/main/Models/BarramundiFish/README.md), CC0. The sample is static; the scene adds a vertex-shader tail sway and swimming/leaping paths.
- `models/seagull.glb` — [Seagull by Innerscene](https://www.innerscene.com/tools/library/3d-parts/seagull-dc308258), CC0. The source model has no animation clip; the scene adds wing pivots, wing beats, fly-by routes, and a landing/take-off sequence.
- `models/maple-leaf.glb` — a single leaf mesh extracted from [Innerscene's CC0 maple tree source](https://www.innerscene.com/tools/library/3d-parts/maple-street-tree-detailed-leaves-006cddf4). Only the leaf is included in the scene; no tree is loaded. Three.js adds tumbling fall, gust, distance scale, and fade-out motion.
- `models/ghost.glb` — [Ghost by Quaternius](https://poly.pizza/m/Iip30bDHmu), marked Public Domain CC0 on Poly Pizza. The local copy came from [models.codelove.in](https://models.codelove.in/models/ghosts-quaternius-ghost/), which identifies the embedded license as CC0 1.0. The scene uses the bundled flying idle animation and pastel lighting.
